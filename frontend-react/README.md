## 📋 **Descripción del Proyecto**

**Sysmicon Frontend React** (`frontend-react/`) es la evolución del cliente web hacia el ecosistema **React + Vite + TypeScript**, diseñada para ofrecer tiempos de arranque instantáneos (HMR), bundles optimizados y una arquitectura reactiva basada en señales (`useSyncExternalStore`) y hooks personalizados.

Coexiste de forma limpia junto al frontend original en Angular (`frontend/`), conectándose de manera transparente al mismo **Backend API REST en PHP 8.3** y al **API Bridge** en producción.

## 🚀 **Cómo ejecutar el proyecto en Local**

### 1. Instalación de Dependencias
```bash
cd frontend-react
npm install
```

### 2. Servidor de Desarrollo (Vite HMR)
```bash
npm run dev
```
Abre tu navegador en `http://localhost:4200/`.

### 3. Compilación para Producción
```bash
npm run build
```
Los artefactos optimizados se generarán en `frontend-react/dist/` (incluyendo `.htaccess` y `manifest.webmanifest`).
