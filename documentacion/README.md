## 🔒 Directrices de Seguridad de la Documentación

- **Sin credenciales**: Esta carpeta y todos los archivos `.md` de documentación técnica están diseñados para ser públicos sin comprometer contraseñas, secretos de API, llaves privadas SSH, tokens de Hostinger ni claves de base de datos.
- **Variables de Entorno**: Solo se documentan esquemas de variables públicas y ejemplos `.env.example`.
- **Despliegues**: Cualquier modificación a los manuales o especificaciones se gestiona con directivas `[skip ci]` para no ejecutar despliegues involuntarios en la infraestructura de producción.
